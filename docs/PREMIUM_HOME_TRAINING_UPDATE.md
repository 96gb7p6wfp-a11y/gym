# Premium Home & Training Experience — 10 November 2026

Baseline: main `fc465cf`, Setline V18 with Volleyball Performance Plan V9.
This changes the existing interface and read-only feedback, not the training
program version, storage schema, backup format or PWA identity.

## Completion

The old record state forced three metric columns while a later CSS rule enlarged
the first value. At 320 px, a decimal-minute duration collided with the set count.
Duration now owns a complete row; count metrics adapt to available width and text
size. Hours/minutes, labels and unusually large values wrap independently. Done
is the primary action; Optional cooldown opens the existing saved stretch routine.
Completion uses a restrained entrance transition and respects reduced motion.

Achievements are computed without changing saved records. Each comparable
movement/equipment configuration contributes at most one achievement. First
performances, new comparison baselines, matched bests and ordinary performances
are distinguished from improved observed load/repetition bests. A stronger prior
set prevents a weaker rep-cohort result being called a record. Known effort must
match; missing effort is disclosed. Unmatched jump protocols, medicine-ball work,
sprints and estimated-1RM formulas do not become spurious completion records.
Load-volume remains available under Performance notes, labeled as logged volume.

## Today

The actual local date and scheduled/completed session remain the main focus.
Below them are Your progress, This week and one Next focus suggestion. Available
strength, jump and body-weight observations replace empty placeholder cards.
The progress section opens the existing detailed Progress view.

Positive strength comparisons require the same movement configuration, equipment,
repetitions and recorded RIR. Missing effort is not fabricated. Jump changes require
compatible measurement setup; approximate profile values are not recorded tests.
Body-weight averages need sufficient check-ins; otherwise a real latest check-in
is identified as such. Consistency counts actual completed sets and recorded sport
activity, never planned attendance. Browsing Train does not change Today's date.

## Exercise technique

All 181 current library choices resolve to structured equipment, setup, movement,
cue, mistake and purpose content. Unknown custom movements keep an honest fallback.
Stable IDs, historical names and prior-performance records remain intact.

The V9 overhead slam is explicitly a two-hand downward floor slam. Forward and
backward overhead throws, rotational scoop throws and half-kneeling landmine
presses have separate identities. Ambiguous older throw/extension choices remain
readable but are excluded from new-library choices rather than silently assigned
a new movement. Specific pull, press, squat, unilateral, carry, hold, approach,
landing and plyometric instructions replace generic coaching where applicable.

Three original offline SVG schematics explain the overhead slam, forward throw
and drop jump. They show direction/sequence, not a comprehensive technique
assessment. No stock photographs, third-party video or fake reviewed demonstration
was added. General video searches are explicitly unreviewed. The slam and forward
throw also link to the reviewed ACE text instructions. Public product and technique
research is recorded in [PREMIUM_HOME_REFERENCES.md](PREMIUM_HOME_REFERENCES.md).

## Starting a workout

Start workout opens Ready to Train? with two unanswered checks: Feeling fit to
train? and Warmed up? Yes + already warmed up starts the eligible workout directly
without inventing completed warm-up checks. Not yet opens the existing specific
quick preparation, including ramp-up/landing guidance where appropriate. The
gentle match primer remains its own preparation workout.

Not quite defaults to recovery; a separate Just tired choice offers a labeled
lighter prescription. Persistent readiness panels are removed from Today, Train
and ordinary previews. Older observations remain compatible and only the chosen
date is updated on an actual continuation. Canceling the check is read-only.

Medical clearance is never changed by the check. Starting re-reads the latest
saved guidance, profile, history and active workout. Changed restrictions are
applied before creation; an existing active session is resumed instead of being
overwritten. A lighter execution of an intentional date draft does not replace
its saved full prescription. Concurrent edits are retained.

## Preservation and verification limits

V9 working sets, V13.1 archives, medical guidance, custom plans, match dates,
recorded weights, nutrition, supplements, active sessions, timers, backups and
offline identity retain their existing storage keys and format. No migration,
storage clear, profile reset, production fixture or third-party asset is needed.
The implementation cannot inspect or restore an actual iPhone's local records.

See the latest section of [VALIDATION.md](../VALIDATION.md) for actual check results.
Browser emulation and root-font enlargement are not physical iPhone, VoiceOver,
native Dynamic Type or locked-screen audio verification. Existing bundle-size
advisories remain. No lint command/configuration exists in this repository.

`scripts/capture-premium-home.mjs` reproduces isolated localhost visual fixtures.
It refuses a remote server URL. Captures are not synthetic user history and must
never be imported into a personal installation. Production deployment is a
separate provider-status and origin-verification step, not implied by this file.
