# Everkinetic exercise illustrations used by Setline

These are **illustrations, not photographs**. The four WebP files cover two
reviewed movements in a starting and raised/extended position:

| Setline exercise ID | Original title | Upstream image numbers |
| --- | --- | --- |
| `leg-extension` | Leg Extensions | `0142-relaxation.png`, `0142-tension.png` |
| `seated-calf-raise` | Seated Calf Raise Using Machine | `0279-relaxation.png`, `0279-tension.png` |

**Creator:** Everkinetic / Greg Priday.

**Source:** [Everkinetic](https://github.com/everkinetic/data), pinned upstream
commit `446bb9a3d0c3beb6b84f7c9d77dfc8af707a2ab6`. Individual original PNG links,
dimensions and output SHA-256 values are in [SOURCE_MANIFEST.json](SOURCE_MANIFEST.json).

**Changes:** Lossless PNG-to-WebP conversion. Original dimensions and decoded
pixels are retained. There is no resizing, cropping, pose change, recoloring or
new endorsement claim. These converted media files remain available under
CC BY-SA 4.0; this notice does not replace the application's separate code license.

**Review:** All four original and converted frames were inspected on 11 November
2026. Leg extension shows the supported seated start and extended-knee position.
Seated calf raise shows bent knees, a thigh restraint and changing heel position.
The calf and leg-extension machines are examples, not the user's identified gym
equipment. Follow the saved exercise instructions and individual guidance.

The source's cropped RDL/biceps images, incomplete-foot lateral-raise artwork
and technically incompatible candidate poses were excluded rather than used to
fill missing slots. BODYCRAFT, ACE and
MuscleWiki photographs are not included in this directory.
